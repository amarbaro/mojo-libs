# mojo-libs v0.1.0

**Released:** 2026-11-05 · **Commit:** `2f2ad60` · **Previous:** first release

## What it does

Index of the amarbaro Mojo libraries: one table (name, what, version, toolchain, our deps, CI badge)
generated from each library's `pyproject.toml`. Read it on GitHub; regenerate it with `scripts/check.sh --write`.

## Highlights

- 33 libraries in one table, each with its version, Mojo pin, in-house dependencies and CI badge.
- The table cannot drift: `scripts/check.sh` fails when it differs from the pyprojects.
