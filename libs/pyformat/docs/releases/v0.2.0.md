# mojo-pyformat v0.2.0

**Released:** 2026-11-04 · **Commit:** `c36bc15` · **Previous:** [v0.1.0](v0.1.0.md)

## What it does

Python's `format()` for numbers in Mojo, with the same digits: `{:.Nf}`, thousands separators, `g`, `e`, and `%`, rounded on the double's exact binary value as CPython does.

## Highlights

- `py_repr(x)`: Python `repr(float)` digit for digit, including the shortest round-trip digits that Mojo 1.2's own float printing gets wrong (it prints two different doubles as `3.000000005061751e+16`).

## Changes

### Added
- `py_repr`, plus 653 `repr` rows in the oracle grid.

## Known limits

- `py_repr` tries up to 17 precisions with `atof`, about 1 µs per value; fine for text output, not for hot loops.

## Upgrade / run

```
from pyformat import py_repr
```
