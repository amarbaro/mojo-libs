## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
Clean-room computer vision in Mojo for the 7900 XTX and 7800X3D: OpenCV-style 2D ops, calibration, 3D/time geometry and CAD export, each checked against an oracle (cv2 5.0, brute force or closed form) and timed against cv2. Plan: `docs/plan.md`. Ideas and sources per track: `docs/provenance/`.

Images and arrays travel as `.mcv` files (`src/mojocv/mat.mojo`, `tools/mcv.py`). 2D vision, features, video and calib3d: `docs/l2d.md`, speed rows `docs/bench.md`.

## Highlights

- 211 2D case rows and 161 3D case rows pass against the cv2 / numpy oracles (tests/run.sh, tests/run3d.sh).
- Real-world checks: 5 chessboard findChessboardCorners + solvePnP, 5 ArUco markers, ORB on a real frame (tests/cases/real.txt).
- Speed rows vs cv2 in docs/bench.md (4 of 39 1080p ops faster; remainder slower, listed as measured).
