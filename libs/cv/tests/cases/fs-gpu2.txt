# fs-gpu2 (R3a absdiff, R3b bilinear resize): the GPU twins of src/mojocv/gpu.mojo against cv2 5.0 and against the CPU run of the same row.

# (float32: within 1e-6), and that a gpu=1 row prints GPU-ARM; a row id fb_* must not (a parameter the kernels do not cover: the
# CPU answer, reported). tests/run.sh runs the same file against cv2 alone.
