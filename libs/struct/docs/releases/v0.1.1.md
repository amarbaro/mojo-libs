# mojo-struct v0.1.1

**Released:** 2026-11-22 · **Commit:** tag `struct-v0.1.1` · **Previous:** [v0.1.0](v0.1.0.md)

## What it does

Pack and unpack binary data in Mojo the way CPython 3.14 `struct` does. Install with `pixi add mojo-struct`
from the `amarbaro/amarbaro` prefix.dev channel.

## Highlights

- `unpack_from_into` unpacks into a list you already own, so a loop over records does not allocate a list per record.
- This is the first release from the monorepo (`amarbaro/mojo-libs`, `libs/struct`).

## Changes

### Added
- `Struct.unpack_from_into(buf, offset, out)`.
### Changed
- Byte-swapped fields load a whole word and then swap it, instead of reading byte by byte.
