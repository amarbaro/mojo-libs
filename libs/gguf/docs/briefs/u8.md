# U8: tokenizer pre-hash, convert_hf_to_gguf_update in Mojo (sonnet lane, branch `lane-u8`)

Read `common.md` first.

The pinned converter names a BPE pre-tokenizer by hashing `str(tokenizer.encode(chktxt))` with HF tokenizers and
looking the sha256 up in a table (`conversion/base.py` get_vocab_base_pre, 95 entries; the update script regenerates
that table from downloaded tokenizers). We do it offline and without Python: tokenize chktxt with our own
implementation of the tokenizer.json pipeline (normalizer, pre-tokenizer regex splits incl. ByteLevel, BPE merges,
added/special tokens, post-processor BOS/EOS as `encode` adds them), hash, look up.

Deliver:
- `src/hf_update.mojo` -> `hf-update DIR` prints exactly `ntok N chkhsh H pre NAME` (`unknown` when not in the table).
- The table generated from the pinned `conversion/base.py` (a generator under `tools/`, its output committed, like U2).
- Regex: use the vendored `uregex` (copy from `~/Projects/mojo/mojo-baro/uregex/`, synced by hand) or your own;
  mojo-baro's `serve/tokenizer.mojo` shows a working Qwen BPE in Mojo (read for ideas, write your own).

Oracle (cached, do not rerun): `.work/oracle/u8/summary.txt` for six local tokenizers (qwen2, qwen35, llama-bpe,
granite-docling, one unknown, deepseek-v3) and `<dir>.ids`, the exact expected ids, to diff against while iterating.

Gate: `tests/u8-gate.sh` must print `PASS 9/9` and exit 0.
