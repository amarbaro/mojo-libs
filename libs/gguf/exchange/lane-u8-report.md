## What was hard

- **The oracle is `AutoTokenizer.encode`, not the file.** qwythos failed by one token (177 vs 178). Raw HF
  `tokenizers` on its tokenizer.json also gives 177: transformers' `Qwen2Tokenizer` ignores the file's
  pre_tokenizer (`[\p{L}\p{M}]+`) and builds its own (`\p{L}+`). `encode_chktxt` takes that built-in pipeline when
  `tokenizer_config.json` names `Qwen2Tokenizer`/`Qwen2TokenizerFast`. Other classes that override the file are
  possible and unmodelled.
- **Mojo abort, 96 GB alloc.** A `String` grown with `+=` and handed to `Set.add` in a nested loop aborted on any
  word of 43+ characters (3 of 6 fixtures). Not minimized to the root; every key is now a fresh byte slice.
  Ledger entry `~/Brain/m.ledger/mojo-gguf.md`.
- `ntok 178` duplicate rows: base.py has 95 `if chkhsh ==` rows, 93 distinct hashes, the later row wins (as the
  script's sequential `if`s do), the generator reproduces that.

## Design calls

- Normalizers: NFC/NFD/NFKC/NFKD/Lowercase fold per character from a table generated out of the check text plus
  printable ASCII (generator asserts it composes to the whole-string result). A character outside both folds to
  itself: only a non-ASCII `normalized=true` added token could notice. Other normalizers FAIL by name.
- Pre-tokenizers modelled: Sequence, Split (Regex or String, all five behaviors, invert), ByteLevel
  (add_prefix_space, use_regex), Digits. Anything else FAILs by name (Metaspace, Whitespace, Punctuation, Bert).
- BPE: byte_fallback, continuing_subword_prefix, end_of_word_suffix, dropout FAIL by name. Merges as `"a b"` strings
  or `[a, b]` pairs. No tokenizer.json (slow-only dirs) is a FAIL: the converter would convert slow to fast.
- `tokenizer_config.json` add_bos_token/add_eos_token are not applied (deepseek-ocr-2 carries its BOS in the
  template post-processor already). A dir where transformers adds a BOS only from the config would differ.
- README not touched (earlier lanes conflicted there on merge); the unit is described in `src/hf_update.mojo` and
  the commit bodies.
