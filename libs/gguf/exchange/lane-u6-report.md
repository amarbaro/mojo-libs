## What was hard

- Bit-equality needed no tricks: the reference does integer math, one int-to-float conversion, then the same
  multiply and add; every integer-times-scale product is exact in f32, so contraction (FMA) cannot differ.
- IQ2_XXS `qs + 4*ib32` is a `uint16_t*`: the 8-byte window starts at byte 8*ib32, not 4*ib32.
- Q3_K scale unpack rewritten as a closed form per scale index: low nibble `byte[k%8] >> 4*(k/8)`, high two bits
  `byte[8+k%4] >> 2*(k/4)`; avoids the 4-word shuffle and any scratch array (kernel-shaped).
- `ksigns_iq2xs[i]` is `i | parity(i) << 7`; computed, not stored (checked by gate iq2_xxs 24/24 and the random-block verifier).
- Codebooks: `comptime Array[UInt64, 2048]` compiles in 2.3 s; `materialize` once per thread chunk and passed by
  reference to the row function (no per-row 16 KB copy).
- Toolchain: `parallelize` is `max.algorithm` on 1.1, `InlineArray` is `Array`; `mojo build` prints a Crashpad
  FATAL line when `MODULAR_CRASH_REPORTING_HANDLER_PATH` points at a missing handler, exit code stays 0 (set it
  empty to silence). Owners of a pointer must outlive its use (ASAP destruction): bit me in a probe, not in the code.
