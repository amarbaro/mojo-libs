# v0.1.0

## Behavior
CSV reader/writer for byte buffers, matching the supported CPython 3.14 quoting
states and errors. Six quoting modes, null/empty distinction, invalid UTF-8
passthrough, dialect validation and field-size rejection.

## API correction
Reader now binds input at construction: Reader(dialect, Span(input)).
next() advances; row() returns views. Row/field views expire on next/reset;
input remains unchanged and outlives the reader and views. The compiler does
not reject every invalid use. field.to_list(), row.to_list() and read_all()
produce owning results; write_all() takes OwnedField values. See docs/api.md.
