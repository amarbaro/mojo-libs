# mojo-csv

CSV reader and writer for Mojo byte buffers, with CPython 3.14 quoting rules.
Fields own their bytes and preserve invalid UTF-8. `is_null` distinguishes None
from an empty string in QUOTE_STRINGS and QUOTE_NOTNULL. Numeric modes validate
ASCII float syntax and return the original byte lexeme, rather than a float.
Errors have library-specific text.

Install Mojo 1.2.0, then use `-I src` from this clone:

```sh
scripts/cap.sh mojo run -I src examples/quickstart.mojo
```

The quickstart reads two records, checks their field counts and writes CRLF CSV.

| Call | Purpose |
|---|---|
| `Dialect.excel()` | Comma, double quotes, CRLF |
| `Dialect.excel_tab()` | Tab separated fields |
| `Dialect.unix_dialect()` | Quote all fields, LF |
| `Reader(dialect).read_all(Span(input))` | Parse owned rows and fields |
| `write_all(rows, dialect)` | Render bytes, one terminator per record |

Controls are individual bytes. Field limit: 131072 bytes. The public API reads a
whole buffer and materializes its output, so large inputs require result memory.
Python file/object APIs, Sniffer, DictReader/DictWriter and Unicode control
characters are excluded. Fields are owned, rather than input views.

Tested with stable Mojo 1.2.0 and the nightly version recorded by
`scripts/nightly.sh`. Run the offline gate with `MOJO=path/to/mojo scripts/ci.sh`.
It compares CPython-generated bytes, null flags and errors, an independent Mojo
scanner, and compiling behavior mutants. Regenerate goldens using CPython 3.14:
`python3 -I tools/gen_vectors.py`.

See [API](docs/api.md), [design and measurements](docs/design.md),
[oracle branch coverage](docs/oracle-coverage.md), and the
[mojo-libs index](../mojo-libs/README.md).
