# mojo-posix v0.1.7

**Released:** 2026-11-22 · **Commit:** tag `posix-v0.1.7` · **Previous:** [v0.1.6](v0.1.6.md)

## What it does

Spawn processes, reap them, read signals and sockets from one poll, and talk over unix sockets from Mojo on Linux.
Install with `pixi add mojo-posix` from the `amarbaro/amarbaro` prefix.dev channel.

## Highlights

- mojo-subprocess and mojo-systemd are now part of mojo-posix, as `posix.subprocess` and `posix.systemd`.
- A unix socket path of 108 bytes now works, as Linux allows.
- This is the first release from the monorepo (`amarbaro/mojo-libs`, `libs/posix`).

## Changes

### Added
- `posix.subprocess` (was mojo-subprocess).
- `posix.systemd` (was mojo-systemd).
### Fixed
- `sock`: a path of 108 bytes is accepted.
