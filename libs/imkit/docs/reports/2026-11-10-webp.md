# Lane webp: pure Mojo WebP decoder (2026-11-10)

VERDICT: LANDED. `webp_decode(d: Span[UInt8, _]) raises -> Tuple[Int, Int, List[UInt32]]` in `src/imkit/webp.mojo`
decodes lossless VP8L, lossy VP8 key frames and ALPH alpha. All 40 fixtures match libwebp with **max channel diff 0**
(the bar was lossless bit exact, lossy <= 2 / mean <= 0.5). No FFI, no dlopen, no Python at run time.

Receipt: `tests/webp_test.sh all` exit 0 (`.work/webp_test.txt`), `scripts/ci.sh` `PASS ci` exit 0 on this tree.

## What is in

- VP8L: predictor (modes 0 to 13, all hit), cross-color, subtract-green, color indexing (1, 2, 4, 16-color bit packing),
  color cache, meta prefix codes, simple and normal prefix codes, LZ77 with the 2-D distance map.
- VP8: boolean decoder, 16x16 / 4x4 / chroma intra prediction, IDCT, WHT, simple and complex loop filters, segments,
  skip probability, 1 to 8 token partitions, libwebp's fancy chroma upsampling to RGBA.
- ALPH: raw and VP8L-compressed, filters none / horizontal / vertical / gradient (each hit by a fixture, checked by
  `tests/webp_fixtures.sh` from the ALPH header bits).
- Container: RIFF, VP8X (canvas checked against the frame), unknown chunks skipped. Animation raises.
- Guards: `MAXPX` per side and product before any allocation (same limit as `png_decode`, a local constant because
  importing `assets` would be circular once the jpeg lane's `image_decode` imports `webp`), prefix-code table budget
  16M entries, every VP8 partition size checked. `assets.mojo` untouched, as the brief says.

## Falsification of the gate

Seven mutants of the decoder were built against the test: no inner loop filter (18 fixtures fail), fancy upsampling
off by one (22), alpha horizontal / vertical un-filter swapped (1 each), partition order (5), unclamped TM4 (22), and one
that survived: resetting the Y2 context on a skipped 4x4 macroblock. libwebp keeps it and so does the code, but no
fixture has a skipped i4x4 macroblock followed by an i16 one, so that rule is verified by reading the reference only.

## Not covered by a fixture

Loop-filter deltas (`use_lf_delta`, the libwebp encoder never writes them; code follows `PrecomputeFilterStrengths`),
the skipped-i4x4 context above, animation (raises), alpha pre-processing level other than 0 or 1 (raises), VP8X
ICC / EXIF / XMP chunks (skipped, not parsed), colour space and clamp-type bits (ignored, as libwebp). Output is
non-premultiplied RGBA; a VP8L header with alpha_is_used = 0 keeps the stream's alpha, as libwebp does.
