# AVIF decoder, lane A: tile parse, intrabc, integration, sequences (2026-11-10)

Status: intra-frame AVIF decodes to planes equal to avifdec / dav1d on 22 fixtures. Branch `lane-avif-a`, no push.

## What exists

| stage | file | gate |
|---|---|---|
| 4 tile parse | `av1state` `av1tile` `av1coef` `av1intrabc` | `tests/av1tile_test.sh`: 34 tiles, every symbol decoder ends at its tile end, 18/18 mutants killed |
| 5 to 7 pixels | `av1dec` (+ lane B `av1recon` `av1ipred`, lane C `av1lf` `av1cdef` `av1lr` `av1grain`) | `tests/avif_yuv_test.sh`: 22 files, every plane (alpha as 4th) exact; `tests/avif_yuv_mutants.sh` 11 killed, 3 listed untested |
| 8 sequences | `avifseq` | `tests/avif_seq_test.sh`: repeat count, timescale, durations, frame pts and sizes equal `avifdec --info`; 6/6 mutants |

Design: the parse never reads a pixel, so `parse_frame` fills frame-wide mode-info grids and decode-order `BlockInfo` / `TxRec` records
(quant values in `quant_pool`); `decode_frame` replays prediction and reconstruction in transform_block order, then LF, CDEF, LR,
crop to the visible size, film grain. All CDFs sit in one pool (`CdfBase` offsets); MV CDFs and DeltaLFMulti are replicated per context.

## Not covered, said plainly

- Inter frames (animation frames after the first), 4:2:2, superres: raise `av1tile:` / `av1dec:` errors, no decode.
- `delta_lf_present = 1` (no encoder reaches it), mdhd version 0 in `avifseq` (libavif writes version 1).
- Mutants no fixture reaches: MV clamp border, sgr `xqd` clip for a zero-radius pass, CFL `MaxLumaW` at a frame edge with skipped luma transform blocks.
- The decoder is single threaded and uses `List[Int]` grids (8 bytes per mi per array).

## Bytes and seconds (memory-optimization)

Hot path: whole decode. Input `big.avif` 1280x720 4:4:4 8-bit, 4 tiles, one run of `avif_yuv_test` (parse + replay + LF + CDEF + crop + compare):
0.12 s, 56 MB peak RSS (empty program 12 MB). `screen.avif` 800x640: 0.06 s, 38 MB. Not tuned; first candidates are `Int` grids to `Int16` / `UInt8`
and the full-frame `copy()` of the frame before CDEF and LR.
