# Plan: 28 style themes and assets for imkit (2026-11-10)

Each of the 28 ComfyUI stock styles becomes an imkit theme whose colours are measured from a generated swatch and must pass
a contrast gate, plus a background and 8 icons in that style. Source: `~/Projects/imports/ComfyUI-v0.43.0/tools/stock/prompts/styles.tsv`.
Mario chose: theme presets, generated assets, gallery screenshots.

## Steps

| # | Step | Size | Check |
|---|---|---|---|
| 1 | Swatch: one ComfyUI image per style (subject "abstract UI background", the row's prefix and suffix), 1280x720, resident `comfy-run` under gpu-wait | GPU ~3 min | 28 PNGs, opened for Mario; his cut list before step 5 |
| 2 | Palette: `tools/palette.mojo`, k-means (k=8) per swatch, roles: panel = largest dark or light cluster, accent = most saturated, text = best contrast to panel | S | text/panel >= 4.5, on_accent/accent >= 4.5, muted/panel >= 3 (WCAG); a planted low-contrast palette fails |
| 3 | Shape per style: radius, round, border, blur from a table keyed by style words (clay, inflated: round and soft; bauhaus, blueprint: square with border; neon, glitch: border and glow) | S | table covers every kept style |
| 4 | `src/imkit/styles.mojo`: generated by `tools/gen_styles.mojo` from steps 2 and 3, never hand-edited; `style(name)`, `style_names()` | M | `tests/style_test.mojo`: every preset passes the contrast gate |
| 5 | Assets per style: background 1280x720 + 8 icons 128x128 (home, search, settings, user, play, folder, bell, close), packed with `tools/pack_atlas.mojo` into `assets/styles/<name>` | GPU ~25 min | 9 files per style, icons have alpha, atlas loads in `Assets` |
| 6 | Gallery: `--style NAME`, shots for all presets with background and icons, contact sheet | S | `gallery_check.sh` PASS on every preset; sheet opened for Mario |
| 7 | README: contact sheet + 6 picked shots; docs/api.md section; skill line; release v0.9.0 via release-note | XS | README fetched on GitHub after Mario's push |

Size budget: all styles <= 20 MB in git (icons PNG, backgrounds JPEG q85); over that, backgrounds ship as a release download.
GPU: steps 1 and 5 as `gpu-wait run --shared --vram <measured>` after the first image is measured.
