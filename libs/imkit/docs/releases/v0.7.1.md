# mojo-imkit v0.7.1

**Released:** 2026-11-08 · **Commit:** `1b26720` · **Previous:** [v0.7.0](v0.7.0.md)

## What it does

An immediate-mode GUI for Mojo apps, drawn by one GPU compose kernel over the app frame. System SDL3 presents the window and FreeType builds the glyph atlas.

## Highlights

- `Window.push(EV_TEXT, text=...)` now delivers the text it was given, also when the string is built at run time (before: garbage bytes).

## Changes

### Fixed
- `Window.push(EV_TEXT)` handed SDL a pointer into a string freed when `push` returned; SDL reads it at `poll()`. A literal (static memory) hid the bug; a run-time string polled back garbage or crashed. `Window` now keeps the bytes alive until `poll()` has read them.
