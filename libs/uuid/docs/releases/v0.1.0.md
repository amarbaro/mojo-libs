# v0.1.0

## Changes

- UUID v3/v4/v5/v6/v7/v8, constants, text and byte conversion.
- Deterministic generator seams and explicit monotonic generator instances.
- RFC 9562 Appendix A/B fixtures; constructor kind/text checks against CPython 3.14.
- Independent 10,000-value brute oracle and compiling behaviour mutants.

## Compatibility

Mojo 1.2 stable and 1.3 nightly. Linux libc and mojo-hashlib are required.
One-shot v6/v7 helpers do not share monotonic state. Use generator instances.
UUID1/2, SafeUUID, MAC lookup and full Unicode digit parsing are omitted.

## Verified

`scripts/check.sh`: RFC replay, constructor errors, brute round trips and generator state.
`scripts/mutants.sh`: compiling mutations must change behaviour and be detected.
Full commands and run receipts are in `.work/report.md` for this local build.
