## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.

Unicode-aware regular expressions for Mojo, built for LLM pre-tokenizers (GPT-2,
Qwen, Llama 3, DeepSeek, Spark) and checked against Python's `regex` by
differential testing. Pure Mojo, CPU, build with `-I src`. mojo-baro's tokenizer
uses a vendored copy (`uregex/`).

## Highlights

- Spark-X2.5's tokenizer is now verified on uregex 0.2: 61/61 cases equal llama.cpp. The 0.2.0 note listed it as UNVERIFIED.
- No code change from 0.2.0.

## Known limits

- Same as v0.2.0 (backtracking engine, no backreferences or variable-length lookbehind, gpt2-style patterns about 5% slower than just before 0.2.0's group support).
- The Spark reference needs the `~/Models/llama.cpp` build; other local llama.cpp builds do not load `spark2_5`.
