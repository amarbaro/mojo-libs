# mojo-toml v0.2.0

**Released:** 2026-10-21 · **Commit:** `1e1edaa` (public) · **Previous:** first release

## What it does

A TOML 1.1 parser written in pure Mojo. It passes the complete official
conformance suite, [toml-test](https://github.com/toml-lang/toml-test) v2.2.0:
**214/214 valid and 467/467 invalid** documents, on Mojo 1.1.0 and on the 1.2 nightly.

```mojo
from toml import parse

def main() raises:
    var doc = parse(open("config.toml", "r").read())
    var server = doc["server"]
    print(server["host"].as_string(), server["port"].as_int())
```

## Highlights

- Full TOML 1.1: every case in the official suite parses or is rejected as the spec says.
- Errors name the position: `toml: duplicate key 'a' at line 2:6`.
- Fast on large files: a 3.1 MB document with 20,000 tables parses in 104 ms.
- Installs with the `mojo` package alone, no MAX.

## Changes

### Added
- TOML 1.1: optional seconds in times, the `\e` and `\xHH` escapes, newlines,
  comments and trailing commas inside inline tables.
- `docs/api.md`, `docs/design.md`, and `skills/mojo-toml/SKILL.md` for coding agents.
- `examples/quickstart.mojo`, `tests/api.mojo`, `tests/bench.mojo`.
- `scripts/conformance.sh`: toml-test, wide-table checks, API test and example in one gate.
- Apache-2.0 licence.

### Changed
- Peak memory on the 3.1 MB benchmark: 135 MB to 94 MB. Parse: 473 ms to 104 ms.
  Lookups: 83 ms to 4 ms for 2,000 nested reads.
- `kind()` and `datetime_kind()` return `UInt8` (was `Int`). Compare with the
  `KIND_*` and datetime constants, not with integer literals.
- Dependency is `mojo>=1.1.0,<1.2` instead of `max[all]`.

### Fixed
- Five compiler warnings; the build is warning-free on 1.1.0 and 1.2 nightly.

## Known limits

- Parse only, no TOML writer. `to_json` is the toml-test debug format.
- Datetimes are returned as text plus a kind, not date objects.
- 9 TOML 1.0 "invalid" tests now parse, because 1.1 allows what they test. No strict 1.0 mode.
- No Mojo package registry yet: install from source, a precompiled `.mojoc`, or by vendoring.

## Upgrade / run

```
git clone https://github.com/amarbaro/mojo-toml && cd mojo-toml && uv sync
mojo run -I src examples/quickstart.mojo
```
