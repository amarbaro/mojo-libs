# mojo-toml (abandoned, kept as a lesson)

A TOML 1.0 parser for Mojo, started 2026-09-19 by a Sonnet lane and stopped after
20 minutes and about 1,300 lines, before any gate ran.

It was never needed. [DataBooth/mojo-toml](https://github.com/DataBooth/mojo-toml)
v0.9.1 (MIT, TOML 1.0 complete, already on Mojo 1.0) existed and parsed
mojo-baro's `docs/settings-template.toml` correctly on the first try. One web
search before briefing the lane would have found it.

The rule that came out of it (Brain `m.ledger/tooling.md`, 2026-09-19): before
briefing any new library or tool lane, search GitHub for it and name the result,
or "none found", in the brief.

Nothing here is tested. Use DataBooth's parser.
